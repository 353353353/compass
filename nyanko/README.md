# にゃんこウォーズ

『にゃんこ大戦争』系のリアルタイム・タワーディフェンスを、ブラウザだけで動くように作ったものです。
画像・音声・外部ライブラリは一切使っていません。キャラも背景も全部 Canvas のパスで描いています。

## 遊ぶには

- **`nyanko/standalone.html` をブラウザで開く** — 全部入りの1枚ファイル。ダウンロードしてダブルクリックでOK。
  誰かに渡すならこれ1つで足ります。
- **`nyanko/index.html` を開く** — 開発用の分割版。こちらも `file://` でそのまま動きます。

`standalone.html` は自動生成ファイルです。ソースを直したら再生成してください。

```
node nyanko/build-standalone.js
```

## 遊び方

1. お金は時間で自動的に増える。画面下のバーが所持金。
2. 下のボタンでネコを出す。出したネコは勝手に右へ進み、敵に当たると殴り合う。
3. **働きネコ**をレベルアップすると、お金の増える速さと所持上限が上がる。序盤に上げるほど後が楽。
4. **ネコキャノン**が溜まったら発射。敵をまとめて吹き飛ばして押し返す。
5. **敵の城を壊せば勝ち。** ただし城を初めて叩いた瞬間にボスが出てくる。

キーボード: `1`〜`6` 出撃 / `Space` キャノン / `W` 働きネコ / `P` 一時停止 / `S` 速度切替
画面のドラッグで戦場を左右にスクロールできます（4秒後に自動追尾へ戻る）。

## 再現した仕組み

原作の「なぜあの遊びが成立しているのか」の部分を、数値ではなく構造として再現しています。

| 仕組み | 内容 |
| --- | --- |
| 攻撃前隙（フォアスイング） | 攻撃は1サイクル `rate` フレーム。ダメージが出るのは `fore` フレーム目だけ。その間は移動できない。射程が長くても前隙が長ければ手数は落ちる |
| ノックバック | 最大体力を `kb` 等分し、その境界を跨ぐたびに後方へ吹き飛ぶ。壁役は吹き飛びやすく、大型は粘る |
| 射程と前線 | 攻撃判定は「自分の位置から射程まで」の区間。後衛の敵は前衛に守られて手が出せない。射程で殴り勝つのがこのゲームの肝 |
| 範囲攻撃 | `area: true` は射程内の全員に当たる。単体攻撃は最前線の1体のみ |
| 属性特効 | 「対赤」「対浮き」「対黒」は該当属性に 与ダメ×1.6 / 被ダメ×0.55 |
| 働きネコ | 所持金の増加速度と上限を8段階で強化。戦闘中にお金を払って上げる |
| ネコキャノン | 時間で充填。自城から一定距離の敵にダメージ＋強制ノックバック |
| ボストリガー | 敵城に初めてダメージを与えた時刻を基準に、ボス側の湧きスケジュールが起動する |
| 再出撃クールタイム | キャラごとに再出撃までの待ち時間。強いキャラほど長い |
| 敵のドロップ | 敵を倒すとその場でお金が入る |

## ステージとキャラ

- ステージ10面（草原 / 湿原 / 洞窟 / 山 / 城）。クリアで次が開放され、初回クリアで新しいネコが仲間になる。
- 自軍8体：ネコ / タンクネコ / ウシネコ（対赤・速い） / バトルネコ / キノコネコ（対黒・範囲） / トリネコ（対浮き・遠距離） / トカゲネコ（射程345） / 巨神ネコ。
- 敵9種：わんこ、あかわんこ（赤）、にょろ（長射程）、ふわこうもり（浮き）、ブロック像（壁）、ゴリさん（黒・範囲）、カバちゃん、あかカバちゃん（ボス）、ブラック大将（ボス）。
- 戦闘で得た XP でネコを Lv20 まで強化、ネコキャノンも Lv10 まで強化できる。進行は `localStorage` に保存。

難易度は「1〜5面は素直に勝てる／6〜8面が壁／10面は強化前提」になるよう、
描画なしのヘッドレス自動対戦で全ステージを回して調整しています。

## ファイル構成

```
nyanko/
├── index.html            画面の骨組み（HUD は DOM、戦場だけ Canvas）
├── style.css             UI
├── standalone.html       ↑を全部埋め込んだ配布用の1枚（自動生成）
├── build-standalone.js   その生成スクリプト
└── js/
    ├── data.js           ユニット・敵・ステージ・経済の全データ
    ├── engine.js         戦闘シミュレーション（描画に一切依存しない）
    ├── render.js         Canvas 描画とキャラのベクター定義
    ├── save.js           進行データ（localStorage）
    ├── ui.js             画面遷移・リスト・戦闘HUD
    └── main.js           ゲームループと入力
```

`engine.js` は DOM も Canvas も参照しません。そのため Node からそのまま読み込んで
AI に自動プレイさせ、全ステージの勝敗と決着時間を一括で確認できます。バランス調整はこれでやっています。

## つくりの方針

- ロジック（`engine.js`）と見た目（`render.js`）を完全に分離。固定タイムステップ 60fps で、
  倍速は「1フレームに何回 tick するか」だけを変える。描画のフレームレートに挙動が左右されない。
- 素材ファイルなし。キャラは `ART` にパスで定義してあり、同じ関数を戦場・アイコン・タイトル絵で使い回している。
- キャラ名・デザインはすべてオリジナル。
